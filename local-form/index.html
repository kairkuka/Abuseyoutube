1. Ссылка и AI-промпт

Если автоопределение не подходит, укажи все три CSS selector. Если оставить все пустыми — работает автоматический сканер.

2. Аккаунты и значения

Один Google OAuth-аккаунт = один YouTube-канал = один Chrome-профиль. Field 1 и Field 3 задаются отдельно для каждого аккаунта.

Нет нужного аккаунта? Сначала добавь его через Accounts → Connect Google account, затем войди этим же Gmail в отдельный Chrome-профиль.

3. Предпросмотр

ИИ создаст отдельный ответ для каждого выбранного аккаунта. Браузеры пока не открываются.

Проверка перед запуском

После запуска откроются отдельные локальные копии уже залогиненных Chrome-профилей. Submit автоматически не нажимается.
